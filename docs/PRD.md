# AI Brain Trainer - 认知训练SaaS

## 项目概述
AI驱动的全功能认知训练平台，专注于前额叶皮层功能提升

## 核心游戏
1. **注意力训练**：Hawkeye（视觉搜索）、Visual Sweeps（动态追踪）
2. **记忆训练**：目标追踪（Target Tracker）、序列记忆
3. **思维速度训练**：快速反应测试、Stroop测试
4. **逻辑推理训练**：模式识别、IQ测试题

## 功能特性
- 4种核心游戏类型
- 自适应难度（根据表现调整）
- 实时进度追踪
- 每日挑战
- 成绩曲线分析
- 周/月报告

## 商业模式
- 免费版：每天3次训练
- Pro版：$9.9/月无限训练
- 年付：$59（打5折）

## 技术栈
- 后端：Go + Gin + SQLite
- 前端：Next.js 14 + Tailwind CSS
- 部署：Vercel + Render
